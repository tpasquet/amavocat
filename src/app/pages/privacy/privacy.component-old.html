Politique de Confidentialité

Introduction

La présente politique de confidentialité a pour but de vous informer sur la manière dont le cabinet d'avocat Aurélie MANIER collecte, utilise et protège vos données personnelles dans le cadre de l'utilisation de ce site internet.

Le cabinet s'engage à protéger la vie privée de ses utilisateurs et à respecter la réglementation applicable en matière de protection des données personnelles, notamment le Règlement Général sur la Protection des Données (RGPD).

Données collectées

Les données personnelles collectées sur ce site sont les suivantes :

  • Formulaire de contact : nom, prénom, email, téléphone, objet et message
  • Cookies et données de navigation : adresse IP, type de navigateur, pages visitées, durée de visite
  • Umami Analytics : données analytiques anonymisées pour améliorer l'expérience utilisateur (solution respectueuse de la vie privée, conforme RGPD)

Finalité du traitement

Les données personnelles collectées sont utilisées pour les finalités suivantes :

  • Répondre à vos demandes de contact
  • Améliorer le contenu et les fonctionnalités du site
  • Analyser le trafic et l'utilisation du site via Umami Analytics (solution open-source respectueuse de la vie privée)
  • Respecter nos obligations légales et déontologiques

Base légale du traitement

Le traitement de vos données personnelles repose sur les bases légales suivantes :

  • Consentement : pour l'utilisation des cookies et le traitement des données du formulaire de contact
  • Intérêt légitime : pour l'analyse du trafic et l'amélioration du site
  • Obligation légale : pour la conservation des données dans le cadre de notre activité réglementée

Durée de conservation

Les données personnelles sont conservées pour les durées suivantes :

  • Formulaire de contact : 3 ans à compter du dernier contact
  • Cookies : 13 mois maximum conformément aux recommandations de la CNIL
  • Données analytiques : 26 mois maximum

Destinataires des données

Les données personnelles collectées sont uniquement accessibles par :

  • Maître Aurélie MANIER et les collaborateurs autorisés du cabinet
  • Google LLC pour le traitement des données analytiques via Google Tag Manager
  • Firebase (Google) pour l'hébergement du site

Cookies

Ce site utilise des cookies pour améliorer votre expérience de navigation et analyser le trafic.

Les cookies utilisés sont les suivants :

  • Cookies essentiels : nécessaires au fonctionnement du site (non désactivables)
  • Cookies analytiques : Google Tag Manager pour mesurer l'audience

Vos droits

Conformément au RGPD, vous disposez des droits suivants concernant vos données personnelles :

  • Droit d'accès : obtenir la confirmation que vos données sont traitées et accéder à ces données
  • Droit de rectification : corriger vos données inexactes ou incomplètes
  • Droit à l'effacement : demander la suppression de vos données
  • Droit à la limitation : limiter le traitement de vos données dans certains cas
  • Droit d'opposition : vous opposer au traitement de vos données
  • Droit à la portabilité : recevoir vos données dans un format structuré
  • Droit de retirer votre consentement : retirer votre consentement à tout moment

Pour exercer ces droits, vous pouvez contacter Maître Aurélie MANIER par email à : aurelie.manier-avocat@outlook.fr

Sécurité des données

Le cabinet met en œuvre toutes les mesures techniques et organisationnelles appropriées pour protéger vos données personnelles contre la destruction, la perte, l'altération, la divulgation non autorisée ou l'accès non autorisé.

Les données sont hébergées sur Firebase (Google Cloud Platform) avec un chiffrement SSL/TLS pour sécuriser les communications.
